# Analizador — ANTLR4 parser for a small `do-while` language

Lexer and parser built with **ANTLR4** and **Node.js** for a teaching language with `do { ... } while (n);` loops, `puts("...")` output and `break`.
Coursework for *Sintaxis y Semántica de los Lenguajes* — Information Systems Engineering, UTN Facultad Regional Mendoza.

## Example

Input:

```text
do { puts("Hola!"); break; } while (1);
```

Output (parse tree):

```text
Parseo exitoso!
(programa (instrucciones (instruccion (bucle do { (sentencia (salida puts ( (cadena " (caracteres (caracter H) (caracter o) (caracter l) (caracter a) (caracter !)) ") ) ;) (terminar break ;)) } while ( (condicion 1) ) ;))))
```

## Run it

Requirements: Node.js 18+.

```bash
cd analizador_utn
npm install
npm start          # type the source code when prompted
```

To regenerate the lexer and parser after changing the grammar (requires Java and the ANTLR 4.13 JAR):

```bash
java -jar antlr-4.13.2-complete.jar -Dlanguage=JavaScript -visitor -o src/generated grammar/analizador.g4
```

## Structure

| Path | What it is |
| --- | --- |
| `analizador_utn/grammar/analizador.g4` | Grammar: lexer and parser rules |
| `analizador_utn/src/generated/` | Lexer, parser and visitor generated by ANTLR |
| `analizador_utn/src/CustomVisitor.js` | Visitor that translates the parse tree to JavaScript (not yet wired into `index.js`) |
| `analizador_utn/index.js` | Entry point: reads source code from the console and prints the parse tree |
| `analizador_utn/ejemplos/` | Sample inputs |

## Language

```antlr
bucle     : 'do' '{' sentencia '}' 'while' '(' DIGITO ')' ';' ;
sentencia : salida* terminar? ;
salida    : 'puts' '(' cadena ')' ';' ;
terminar  : 'break' ';' ;
```

Whitespace is skipped, so spaces inside strings are not preserved.
